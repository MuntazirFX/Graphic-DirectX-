# Credits

This repo is a **fan toolkit** for loading original Joymania data files on iOS.
It is **not** Joymania software and **not** a decompile of any `.exe`.

## Santa Claus in Trouble (2002)

From the shipped PC manual / installer text (CDV + Joymania, 2002):

| Role | People |
|---|---|
| Programming | Petr Vlček, Peter Ohlmann |
| Graphic design | Adam Sprys, Peter Ohlmann |
| Publisher | CDV Software Entertainment AG |
| Producer at CDV | Achim Heidelauf |
| Studio | Joymania Development |

Joymania Development (previously Joymania Entertainment) is an independent German studio founded in 1997 by **Peter Ohlmann** and **Adam Sprys** (Mülheim an der Ruhr). Official site: https://joymania-games.com/

Related titles using the same XPK / `.x` / `.dat` family:
- Santa Claus in Trouble (2002)
- Rosso Rabbit in Trouble (2003)
- Santa Claus in Trouble ... again! (2004)
- Santa Claus in Trouble HD (2020) — different `data.pak` container

Music on the 2002 release is commonly credited in the community to **Jeysym** (also the author of the HD pak tool).
